# Техническое задание

## Название проекта

**AsciCalc** — расширяемый математический калькулятор с элементами CAS и пиксельным интерфейсом.

## Цель проекта

Цель проекта — разработать модульный калькулятор на C++20, который умеет выполнять не только базовые арифметические операции, но и более сложные математические вычисления: работу с рациональными числами, матрицами, многочленами и математическими функциями.

Проект должен быть легко расширяемым: новые типы данных, функции и интерфейсы должны добавляться отдельными модулями без полной переработки программы.

## Основной функционал

- арифметические операции: сложение, вычитание, умножение, деление;
- точные рациональные вычисления;
- длинная арифметика для больших целых чисел;
- переменные и присваивание значений;
- функции одного и нескольких аргументов;
- матрицы: ввод, сложение, умножение, определитель, след, ранг, обратная матрица;
- многочлены: ввод, сложение, умножение, производная, интеграл, вычисление в точке;
- LaTeX-like ввод для матриц и многочленов;
- консольный интерфейс REPL;

## Как пользователь работает с программой

Пользователь может работать с программой двумя способами.

### Консольный режим

Пользователь запускает `SpriteCalc.exe`, вводит выражение и получает результат.

Примеры:

```text
1 / 3 + 1 / 6
phi(10)
[1,2;3,4] * [5;6]
det([1,2;3,4])
derivative({1,2,3})
integral({0,2})
selftest
```

Для выхода используется команда `q`, `quit` или `exit`.


Основные классы и модули:

- `core::Value` — универсальный тип значения на основе `std::variant`;
- `core::Context` — хранение переменных пользователя;
- `math::Rational` — рациональные числа;
- `math::Matrix` — матрицы;
- `math::Polynomial` — многочлены;
- `parser::Lexer` — разбор строки на токены;
- `parser::Parser` — построение выражения через алгоритм Shunting Yard;
- `app::Repl` — консольный интерфейс;

Контейнеры:

- `std::vector` — элементов матриц, коэффициентов многочленов, токенов и инструкций;
- `std::unordered_map` — хранение переменных в контексте;
- `std::variant` — хранение разных математических типов в `Value`;
- `std::string` — хранение пользовательского ввода, имен переменных и функций;
- `std::unique_ptr` и RAII-подход — управление ресурсами без ручного `new/delete`.

## Входные и выходные данные

### Входные данные

Входными данными являются строки, которые вводит пользователь:

- арифметические выражения;
- матрицы;
- многочлены;
- команды REPL;
- команды интерфейса;
- вызовы функций.

Примеры входных данных:

```text
2 + 2
phi(36)
[1,2;3,4]
det([1,2;3,4])
{1,2,3}
derivative({1,2,3})
```

### Выходные данные

Выходными данными являются:

- результат вычисления;
- сообщение об ошибке;
- список переменных;
- справка;
- результаты тестов;

Примеры:

```text
4
12
[1,2;3,4]
{2,6}
error: division by zero
selftest: 58 passed, 0 failed
```

## Стиль работы с Git

Выбран стиль `main + feature branches`.

- `main` содержит стабильную версию проекта.
- Для каждой задачи создается отдельная ветка.
- Примеры веток: `feature/parser`, `feature/matrix`, `docs/tz`.
- Перед объединением ветки проект должен собираться без ошибок.
- Коммиты должны быть короткими и понятными.
