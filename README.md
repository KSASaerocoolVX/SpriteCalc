# SpriteCalc

**SpriteCalc** (внутреннее имя сборки — `AsciCalc`) — расширяемый математический калькулятор на **C++20** с элементами компьютерной алгебры (CAS) и пиксельным интерфейсом на **SFML 3**.

Проект сделан модульным: новые типы данных, функции и элементы интерфейса добавляются отдельными модулями C++20 без переработки всей программы.

---

## Возможности

- Точная арифметика над рациональными числами (без потери точности с плавающей точкой).
- Базовые операции: сложение, вычитание, умножение, деление.
- Собственный лексер (без `std::regex`) и парсер выражений на алгоритме Shunting Yard.
- Хранение переменных пользователя через контекст (`core::Context`).
- Универсальный тип значения `core::Value` на основе `std::variant`.
- Пиксельный графический интерфейс на SFML: калькулятор, кнопки, фон с шейдерами.
- Редактор математических выражений с визуальными узлами: дроби, степени, текст, строки.
- Матрицы: сложение, умножение, определитель, след, ранг, транспонирование, обратная.
- Многочлены: вычисление в точке, производная, интеграл.
- Функции теории чисел (НОД, функция Эйлера и др.), комплексные и модулярные числа.
- Два режима работы: графический (SFML) и консольный REPL с командами `help`, `vars`, `selftest`, `bench`.

## Требования

- Компилятор с поддержкой **C++20 modules** (MSVC 19.3+ / Clang 17+ / GCC 14+).
- **CMake** 3.28 или новее.
- Генератор **Ninja** (рекомендуется для модулей).
- **SFML 3.0.0** — скачивается автоматически через `FetchContent`, ставить вручную не нужно.

## Сборка

```bash
# из корня проекта
cmake -S . -B build -G Ninja
cmake --build build
```

Исполняемый файл `AsciCalc` появится в каталоге `build`. Каталоги `UI/assets` и `UI/shaders` копируются рядом с ним автоматически после сборки.

```bash
cd build
./AsciCalc
```

> В CLion проект открывается напрямую: каталог сборки — `cmake-build-debug`, стартовая цель — `AsciCalc`.

## Использование

Доступны два режима работы.

**Графический режим.** После запуска открывается окно `SpriteCalc` (800×800) с пиксельным калькулятором — ввод и вычисление выражений выполняются через интерфейс.

**Консольный режим (REPL).** Пользователь вводит выражение и сразу получает результат. Примеры ввода:

```text
1 / 3 + 1 / 6
phi(10)
[1,2;3,4] * [5;6]
det([1,2;3,4])
derivative({1,2,3})
integral({0,2})
selftest
```

Выход из REPL: `q`, `quit` или `exit` или ctrl+c.
